# 字体文件说明

## 仓耳渔阳体 (Tsanger Yu Yang T)

本项目履历书纸张可以优先使用 `TsangerYuYangT-W03.ttf`，用于提供有一定风格、同时兼容中日文字回退的纸张排版。该字体二进制不随公开仓库分发；部署者只有在确认再分发授权后，才应将文件放入本目录。

### 字体回退顺序

网页会按以下顺序使用履历纸张字体：
1. 仓耳渔阳体（项目内置）
2. Noto Sans SC（中文回退）
3. Noto Sans JP（日文回退）
4. Zen Maru Gothic（在线字体回退）
5. Microsoft YaHei（系统字体）

如果部署环境无法读取项目内字体文件，页面仍会使用上述回退字体，不影响编辑和导出功能。

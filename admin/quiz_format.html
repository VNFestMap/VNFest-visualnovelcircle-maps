VNFest 题库 JSON 规范
返回题目设计器

文件结构

一份题库是一个 JSON 文件，包含 questions（题目列表）和 settings（考试设置，可省略）两部分。在题目设计器顶栏点「导入」即可载入。

{
  "questions": [ /* 题目，见下文 */ ],
  "settings": { /* 考试设置，可省略，见下文 */ }
}

题型一览

type题型答案怎么填判分规则
single单选题answer 填 1 个选项序号（从 0 起）全对得分
multiple多选题answer 填多个序号，如 [0,1,3]按考试设置：全对得分，或选对得分、选错扣分
judge判断题选项固定为 对/错；answer 填 [0]（对）或 [1]（错）全对得分
fill_blank填空题answer_text 填参考答案文本忽略大小写与首尾空格后比对
fill_multi多空填空answer_texts 填答案数组，数组长度即空数（1–10）逐空判分，得分 = 分值 × 正确空数 ÷ 总空数
order排序题options 的排列顺序即正确答案，无需 answer 字段按位置正确率给分

选项序号从 0 开始：第 1 个选项是 0，第 2 个是 1，依此类推。

题目字段

字段适用题型必填说明
type全部必填题型，取值见上表
question全部必填题干
options单选/多选/判断/排序必填选项文本数组，至少 2 个；判断题固定 ["对","错"]；排序题最多 20 个
answer单选/多选/判断必填正确选项序号数组（整数）
answer_text填空必填参考答案
answer_texts多空填空必填逐空参考答案数组，1–10 个，均不得为空
points全部建议分值 1–100，省略默认 10；最终成绩按总分折算百分制
explanation全部可选交卷后展示给参与者的解析
image全部可选题干图，仅限设计器上传生成的站内地址（data/quiz_images/…）
option_images有选项的题型可选选项图数组，长度必须与选项一致，无图的选项留空字符串 ""

完整示例

{
  "questions": [
    {
      "type": "single",
      "question": "《千恋＊万花》中，有地将臣第一个遇见的可攻略角色是谁？",
      "options": ["芦花", "芳乃", "茉子", "丛雨"],
      "answer": [0],
      "points": 10,
      "explanation": "序章首先登场的是芦花。"
    },
    {
      "type": "multiple",
      "question": "以下作品中，属于柚子社出品的是？",
      "options": ["天神乱漫", "Parquet", "青夏轨迹", "管乐恋曲"],
      "answer": [0, 1, 3],
      "points": 15
    },
    {
      "type": "judge",
      "question": "《交汇协奏曲》被玩家称为「桐月的绝唱」。",
      "options": ["对", "错"],
      "answer": [0],
      "points": 5
    },
    {
      "type": "fill_blank",
      "question": "《秽翼的尤斯蒂娅》中，「牢狱」是由第几次大崩落产生的？",
      "answer_text": "1",
      "points": 10
    },
    {
      "type": "fill_multi",
      "question": "被誉为「姬野家的坏女人」的是姬野星奏与谁？",
      "answer_texts": ["姬野永远"],
      "points": 10
    },
    {
      "type": "order",
      "question": "将 Key 社以下作品按发售时间先后排序：",
      "options": ["Kanon", "AIR", "CLANNAD", "Little Busters!"],
      "points": 10,
      "explanation": "1999 / 2000 / 2004 / 2007。"
    }
  ],
  "settings": {
    "shuffle": true,
    "shuffle_options": true,
    "pick_count": 0,
    "time_limit": 20,
    "multiple_partial": true,
    "result_mode": "immediate"
  }
}

考试设置（settings）

字段取值说明
shuffletrue / false题目乱序
shuffle_optionstrue / false选项乱序（排序题始终打乱呈现，不受此开关影响）
pick_count0 或正整数每次随机抽题数量，0 = 全部出
time_limit0–180限时（分钟），0 = 不限时；超时提交不通过、不签发
multiple_partialtrue / false多选半分：开 = 选对得分、选错扣分；关 = 全对才得分
result_modeimmediate / pass_only / hidden立即显示分数与解析 / 只显示通过与否 / 交卷后不显示

保存前检查清单

  • 题干不为空；每题分值在 1–100 之间
  • 选择题选项 ≥ 2 个，且答案序号不越界；单选题答案只能有 1 个
  • 填空题参考答案不为空；多空填空每个空都有答案
  • 选项图数组与选项等长（无图位置用 "" 占位）；图片地址必须是设计器上传生成的站内地址
  • 抽题数不超过总题数；限时不超过 180 分钟

以上规则与系统保存时的校验完全一致——导入后点「完成」若提示错误，按提示定位对应题目即可。

使用方式

1. 按本规范编写题库，保存为 .json 文件（UTF-8 编码）。

2. 管理后台 → 考核设置 → 新建或编辑「知识问答」考核 → 打开题目设计器。

3. 顶栏点「导入」选择文件；检查无误后点「完成」带回，保存或发布考核。

4. 也可反向操作：在设计器里出好题后点「导出」，得到的文件同样符合本规范，可存档或交接给他人。

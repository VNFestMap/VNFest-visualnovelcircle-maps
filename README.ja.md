## これは何

**VNFest**（Visual Novel Festival）は、単なるサークルディレクトリではありません。ビジュアルノベル同好会のために作られた軽量運営プラットフォームであり、地図ナビゲーション、サークル情報管理、メンバー管理、イベントカレンダー、出版物投稿、企画コラボレーション、投票大会、Wiki 百科を一つの完全なフローに統合しています。

仲間を探している同好、サークル情報を管理する責任者、イベントを企画する運営者、あるいは百科に何か書きたい編集者——VNFest には、それぞれの役割に対応する入口が用意されています。

```text
同好会を発見 → 詳細を確認 → 参加申請 → イベントに参加 → 出版物 / Wiki に投稿 → 企画大会に参加
```

> **オンライン体験：** [https://www.map.vnfest.top](https://www.map.vnfest.top)
> 新規登録なしでゲストモードにて地図とサークル情報を閲覧できます。

## 機能詳細

### 🗺️ 地図と発見

VNFest のコア体験は、インタラクティブな地図から始まります。

中国地図はすべての省をカバーし、日本地図は都道府県レベルまで正確に表示されており、各地域にその地で登録済みのビジュアルノベル同好会が示されています。任意のエリアをクリックすると、その地域のサークル一覧が表示され、地図モードとリストモードを自由に切り替えることもできます。

地図ブラウジングのほかに、省インデックス、キーワード検索、タイプ別フィルタリング（学校サークル / 民間団体 / オンラインコミュニティ）、多次元ソートなどの発見手段も提供されています。一つの同好会は複数の省に紐付けることができ、広域組織も正しく表示されます。

訪問者はログインなしですべての地図データとサークル詳細を閲覧できます。ログイン後は管理入口が追加され、担当するサークル情報を編集できるようになります。

### 📋 サークル情報

各サークルには完全な情報ページがあり、名称、地域、所属校、組織タイプ、連絡先、詳細紹介が含まれます。

責任者はサークルアバターのアップロードとトリミング、サークル紹介と連絡先の管理が行えます。システムは三段階の権限体系をサポートしています：一般メンバー、サークル責任者、スーパー管理者で、役割ごとに異なる操作画面が表示されます。

メンバー管理方面では、参加申請、責任者による承認、バインディングコードによるクイック参加などのフローをサポートしています。サークル詳細ページにはおすすめボード（他のユーザーが好きなサークルを推薦できる）と伝言板（メンバーや訪問者が書き込んで交流できる）も統合されており、サークルページを単なる静的情報ではなく、生きたコミュニティページにしています。

### 📅 イベントと出版物

**イベントシステム** はカレンダービューとリストビューの二つの閲覧方式を提供します。サークル責任者はイベントの公開、投稿管理、コンテンツの審査、参加データの追跡が行えます。ユーザーはイベントページから直接参加申込ができます。

**出版物投稿** では、責任者が原稿募集告知を公開し、投稿ステータス（審査待ち / 採用済み / 公開済み）を追跡し、出版物を主催サークルに紐付けることができます。

**GalOnly イベント** には独立した特集入口と審査パネルがあり、さらに完全な **Staff 募集システム** が装備されています——ユーザーはオンラインでスタッフ申請を提出でき、管理者が投票と審査フローを通じて選考し、最終的にシフト名簿を確定します。

### 🏗️ 企画ハブ

企画ハブはサークル間コラボレーションの中心です。

責任者は企画プロジェクトを作成し、他のメンバーを招待して役割（企画 / アート / 文章 / 技術）を割り当てることができます。各プロジェクトには明確なステータス追跡があり——準備中、進行中、完了、保留まで一目で把握できます。プロジェクトはファイル紐付けもサポートしており、チーム間での素材やドキュメントの共有が容易です。

すべての企画はサークル広場に集約して公開表示され、より多くの人に進行中のコミュニティプロジェクトを知ってもらうことができます。

### 🏆 投票大会

VNFest には統一された投票ベースシステムがあり、多段階・多ラウンドの柔軟な設定をサポートしています。その上に二つの特徴的な大会が構築されています：

**十二器（Twelve）** — 作品向けの選出システムです。フローはノミネート → 予選 → グループ別スコアリング/投票で、最終的に年間 Top 12 ビジュアルノベルを選出します。データソースは優先的に Bangumi から検索し、VNDB データで補完、手動ノミネート入口も維持されています。

**萌戦（Moe）** — キャラクター向けの対戦システムです。フローはノミネート → 予選 → 2 のべき乗人数による 1v1 トーナメントで、最終的にもえ王を選出します。トーナメント段階には独立した対戦図可視化コンポーネントがあり、ズーム、パン、ドラッグ操作をサポートし、各試合の投票ステータスと票数をリアルタイムで表示します。

両大会ともに独立した Hub ページ、詳細ページ、大会管理バックエンドを備え、ノミネートから決勝までの全プロセスをオンラインで完結できます。

### 👤 ユーザーセンター

v2.0 で全面リニューアルされたユーザーセンターは、従来の単体 HTML ページから React 18 ベースの SPA アーキテクチャに移行しました。

プロフィール編集、サークル管理、メッセージ通知、成長システムなどのワンストップ操作体験を提供します。ページの読み込みはより速く、インタラクションはより滑らかになり、今後の機能拡張に向けた堅牢なアーキテクチャ基盤を築いています。

ローカルアカウントでの登録/ログイン、メール認証コード、パスワードリセット、および QQ と Discord のサードパーティ OAuth ログインをサポートしています。

### 📖 Wiki 百科

VNFest Wiki は百科式のレイアウト——左側ナビゲーションバー + 右側コンテンツエリアを採用しており、従来の Wiki サイトと一貫した操作性です。

エディタはビジュアル編集をサポートし、ページ内に画像、インフォボックス、タイムライン、外部リンク、構造化された段落を挿入できます。コンテンツは中国語と日本語のバイリンガルをサポートし、異なるユーザー層の編集ニーズに応えます。

編集完了後、Wiki ページは直接静的 HTML として生成・公開でき、追加のビルドステップは不要です。Wiki ホームページには「最近更新」と「資料公開ライブラリ」へのクイックアクセス入口があり、閲覧と管理を容易にしています。

### 📚 資料公開ライブラリ

サークル出版物向けのデジタルアーカイブシステムです。PDF および画像フォーマットのアップロードをサポートし、管理者は出版物のメタデータ（タイトル、著者、公開日、関連サークルなど）を管理できます。

内蔵の PDF リーダーツールにより、3D ページめくり効果でのプレビューをサポートしており、ユーザーはダウンロードせずにオンラインで出版物の内容を閲覧できます。

### 🌌 サークル広場

サークル広場はプラットフォーム全体の情報集約ポイントであり、すべての公開大会、企画、イベントを一元的に表示します。

深遠な宇宙をテーマにしたデザインを採用し、5色のイベントカードによる分類表示で、視覚的に異なるタイプのコミュニティ活動を瞬時に識別できます。日中バイリンガル切り替えをサポートし、異なる言語のユーザーもスムーズに閲覧できます。

### 🌟 連合星図

連合星図は視覚的に没入感のある探索入口です。

Cinematic Frontend v2 デザインを採用——放射状グラデーション背景、レーダースキャンアニメーション、ビネット効果を組み合わせ、宇宙探検の雰囲気を演出しています。没入モードをサポートし、HUD 要素を非表示にして、ユーザーが星図の閲覧に完全に没入できるようにします。

## 技術アーキテクチャ

```text
┌──────────────────────────────────────────────────────┐
│                    浏览器 / 客户端                      │
│   HTML + CSS + Vanilla JS    │    React 18 SPA       │
│   D3.js 7 (地图可视化)        │   (用户中心)            │
└────────────────┬─────────────┴───────────┬───────────┘
                 │  fetch() / REST         │
┌────────────────┴─────────────────────────┴───────────┐
│                   PHP 8.x 后端                         │
│   api/*.php (端点)  │  includes/*.php (公共模块)        │
│   __DIR__ 相对路径引用，无框架依赖                        │
└────────────────┬─────────────────────────────────────┘
                 │
┌────────────────┴─────────────────────────────────────┐
│                     数据层                             │
│   JSON 运行时文件  │  SQLite / MySQL via PDO            │
│   data/*.json     │  data/galgame.db                  │
└──────────────────────────────────────────────────────┘
```

| 層 | 技術 |
|---|---|
| フロントエンド | HTML · CSS · Vanilla JavaScript · React 18 · D3.js 7 |
| バックエンド | PHP 8.x（`__DIR__` 相対パス参照、ゼロフレームワーク依存） |
| データ | JSON ランタイムファイル · SQLite / MySQL via PDO |
| ビルド | Vite（ユーザーセンター SPA）|
| テスト | Node.js コントラクトテスト（39+ テストスクリプト） |
| デプロイ | Docker · GitHub Actions CI/CD · Watchtower 自動ローリングアップデート |
| 国際化 | 中国語 / 日本語 バイリンガルサポート |

## クイックスタート

### 環境要件

- PHP 8.0+（`mbstring`、`pdo_sqlite` 拡張を含む）
- Node.js 18+（テストとビルド用）
- Git

### ローカル実行

```bash
# 1. 克隆仓库
git clone https://github.com/VNFestMap/china-visualnovelcircle-maps.git
cd china-visualnovelcircle-maps

# 2. 安装依赖
npm install

# 3. 准备配置文件
cp config.example.php config.php
# 编辑 config.php，设置数据库路径和站点 URL

# 4. 启动 PHP 开发服务器
php -S 127.0.0.1:8000
```

ブラウザで以下の URL にアクセスしてください：

| ページ | URL |
|------|------|
| ログイン / 新規登録 | `http://127.0.0.1:8000/login.html` |
| ゲストモード閲覧 | `http://127.0.0.1:8000/index.html?guest=1` |

### テストの実行

```bash
npm run check
```

このコマンドは全 40+ のコントラクトテストを実行し、フロントエンドインタラクション、Wiki 生成、アップロード契約、サークル編集、バックエンドプライバシー、成長システム、ユーザーページ、国際化、パフォーマンス最適化、投票フロー、ボット同期、プロジェクト全体の健全性をカバーします。

## デプロイ

プロジェクトは Docker コンテナ化デプロイをサポートしており、GitHub Actions 経由で自動的にイメージをビルドし GHCR にプッシュします。サーバー側の Watchtower が自動プルとローリングアップデートを担当します。

```bash
# 使用 Docker Compose 一键部署
docker compose up -d

# 或使用部署脚本（含数据备份和权限设置）
bash scripts/deploy.sh
```

詳細なデプロイ設定、環境変数の説明、運用手引は [`DEPLOY.md`](DEPLOY.md) を参照してください。
